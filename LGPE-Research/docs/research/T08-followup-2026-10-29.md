# T08 follow-up — Blender model conversion retry (2026-10-29)

## Finding and scoped workaround

The remaining `.gfbmdl` failure was reproduced with Blender 5.1.2 (build hash `ec6e62d40fa9`) and the pinned importer `Pokemon-Switch-Model-Importer-Blender@bb597581916c7407385afb5461efe4d2ae2f38f9`. The source is `bin/field/model/s001r01/s001r0101_00.gfbmdl` (3,794,156 bytes; SHA-256 `8077968c4a0a0d59071df2c26bdcdecef53dd537cae814988b3d570bd45d24ff`). The original worker reached mesh index 27, named `plant17`, and Blender raised `EXCEPTION_ACCESS_VIOLATION`. The previous manifest run recorded `0x00007FF6F0C2B96E`; my instrumented reproduction recorded `0x00007FF7F7F0B96E` after relocation. The crash dump stack is `mesh_normals_corner_custom_set` → `mesh_set_custom_normals` → `mesh_set_custom_normals_from_verts` → `Mesh_normals_split_custom_set_from_vertices_call`.

I inspected the source table with the pinned generated model bindings. Mesh 27 has 254 vertex rows, a 48-byte stride, two polygon groups containing 360 and 486 `uint16` indices, all indices in range, and 254 finite approximately unit-length normal vectors. Twenty-five triangles in the first polygon group repeat a vertex index. The data checks do not identify a corrupt index or non-finite normal, and they do not prove why Blender crashes.

`src/lgpe_research/blender_compat.py` now gates one adapter patch on that exact source SHA-256. It fails closed if the pinned importer's target call is absent or duplicated. For that file alone, `assets_blender.py` bypasses `normals_split_custom_set_from_vertices` for mesh index 27 only when the importer names it `plant17`; all other meshes retain the upstream call. `tools/src/Pokemon-Switch-Model-Importer-Blender` remains unchanged. This preserves the mesh geometry but omits application of that mesh's source custom normals, so its shading may differ. The GLB is therefore a successful geometry export with this explicit normal limitation, not a fully lossless model conversion.


The retry completed with the target row `DECODED` and source-wide `FAILED=0`.
