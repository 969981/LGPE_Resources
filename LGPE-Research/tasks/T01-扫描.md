# T01 — 扫描、扩展名、magic 和关联关系

**优先级：** P0  \n**依赖：** T00

## Codex 子任务提示词

请先阅读项目根目录的 `AGENTS.md`、`CODEX_MASTER_PROMPT.md` 和此文件。你负责 T01：扫描、扩展名、magic 和关联关系。**不能只写计划或只生成框架**，必须推进到实际验证，若源资源/工具不可用则准确记录阻塞和已完成的独立部分。严禁改动 `../1.0.2/`、添加游戏数据到 Git。

### 执行步骤

1. 执行 `uv run lgpe scan` 生成 `manifests/files.csv`，比较树快照 `docs/catalog/snapshot_file_inventory.csv`；真实源可选做 SHA256 哈希扫描。
2. 按分区、扩展名、路径前缀、魔数和文件大小统计，查出重名、缺失、零长度及 MIME 误识别。
3. 对 `.dat`、`.tbl`、`.bin` 采样做字节级鉴别；统计匹配 dat/tbl 的实际对数。
4. 把后续解码队列导出，所有记录要有最初文件来源。

### 验收门槛

- [ ] 有 scan-summary、格式分布和差异解释；未识别不标记为解码成功。

### 交接输出

将样本路径、原始文件哈希、工具源码 commit、原始/导出签名、测试命令、运行结果、失败明细、后续接口写入 `docs/research/T01-notes.md`；修订 `tasks/INDEX.md` 和 `docs/research/STATUS.md`，提交单独的 Git commit。没有完成真实试解时只能填 `IN_PROGRESS/BLOCKED`，不可标记为 `VALIDATED`。
